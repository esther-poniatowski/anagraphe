# CLI Reference

## Global Options

```
anagraphe [OPTIONS] COMMAND [ARGS]
```

| Option | Description |
| ------ | ----------- |
| `--version`, `-v` | Display the version and exit. |
| `--help` | Display the help message and exit. |

## Commands

### `info`

Display version and platform diagnostics.

```sh
anagraphe info
```
